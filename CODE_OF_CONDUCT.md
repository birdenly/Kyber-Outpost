# Code of Conduct

## Our Pledge

We pledge to keep participation in **Kyber Outpost** a respectful and harassment-free experience for everyone.

## Standards

Examples of positive behavior:

- Using welcoming and respectful language
- Accepting constructive feedback gracefully
- Focusing on practical improvements for the project and its users

Unacceptable behavior includes:

- Harassment, personal attacks, or trolling
- Offensive, discriminatory, or sexualized language or imagery
- Publishing others' private information without permission

## Scope & Enforcement

This Code of Conduct applies to all interactions within the repository (issues, pull requests, discussions, and commits).

Maintainers may remove, edit, or close comments, commits, issues, or pull requests that do not follow these guidelines, and may block contributors for repeated or severe violations. Issues regarding conduct in this repository can be raised directly with the repository maintainer on GitHub.
